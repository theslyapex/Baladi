# بلدی؟ | Baladi

بازی مرحله‌ای واژه‌سازی فارسی، ساخته‌شده با Godot 4 برای Android.

## وضعیت فعلی
این مخزن در حال توسعه است. نسخه فعلی، هسته اولیه قابل‌بازی را شامل می‌شود:
- انتخاب حروف و ساخت واژه
- بررسی پاسخ و تکمیل خانه‌های جدول
- چند مرحله داده‌محور
- سکه، راهنمای حل واژه و ذخیره پیشرفت محلی
- رابط فارسی با چیدمان عمودی

## اجرای پروژه
1. Godot 4.3 یا جدیدتر را نصب کنید.
2. فایل `project.godot` را Import کنید.
3. پروژه را اجرا کنید.

## ساختار
- `scenes/`: صحنه‌های بازی
- `scripts/`: منطق بازی و ذخیره‌سازی
- `data/levels/`: داده مراحل، جدا از کد
- `.github/workflows/`: فرایند ساخت خودکار

## نکته انتشار
شناسه بسته فعلی آزمایشی است. پیش از انتشار باید شناسه نهایی، آیکون‌ها، مجوزها، امضای نسخه انتشار و SDK پرداخت رسمی بازار/مایکت تنظیم و آزمایش شوند. پرداخت واقعی هنوز پیاده‌سازی نشده است.
